# Yomi 読み

## Git

- Commit messages: Conventional Commits (`feat:`, `fix:`, `refactor:`, `test:`, `docs:`, `chore:`, optional scope), written in English. Subject ≤50 chars. The `caveman-commit` skill may be used.
- No `Co-Authored-By` and no Claude attribution in commits or PR descriptions.
- Commit or push only when the user asks.
